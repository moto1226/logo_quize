# quiz-skill 识标挑战

## 业务目标

帮助用户通过微信 AI 快速进入 Logo 识别练习、选择题型、查看题库概况和最近一次练习结果。

## 原子接口

| 接口 | 作用 | 前置条件 |
| --- | --- | --- |
| getQuizSummary | 查看题库规模、题型和主要行业分布 | 无 |
| startQuiz | 根据用户意图进入练习页 | 用户表达开始练习或指定题型 |
| getLatestResult | 查看最近一次练习成绩 | 无 |

## 业务约束

1. 识别答案、判题、计时和结果统计都由小程序原有页面完成，Agent 不参与判题。
2. 用户说“开始练习”“来一组 Logo 题”“随机练习”时，调用 `startQuiz` 且 `mode=mixed`。
3. 用户说“看 Logo 猜品牌”“基础识别”时，调用 `startQuiz` 且 `mode=logo_to_brand`。
4. 用户说“看品牌选 Logo”“反向记忆”时，调用 `startQuiz` 且 `mode=brand_to_logo`。
5. 禁止 Agent 直接告诉用户题目答案，禁止替用户选择答案。
6. 查询成绩时只调用 `getLatestResult`，没有成绩则引导用户先完成一轮练习。

## 用户意图示例

- “开始识标”
- “来一组 Logo 题”
- “我想练看 Logo 猜品牌”
- “练反向记忆”
- “现在题库有多少品牌”
- “我上次答得怎么样”
